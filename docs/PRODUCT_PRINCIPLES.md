# Product principles (first principles)

Pragati is the **work-tracking system for Earth — and Mars**.  
Not pharma. Not “project theater.” One shared board that matches reality.

**Customer:** every person who has to move work: builders, leads, founders, crews on a factory floor, a habitat ops team.  
**Test:** *Would someone only open Pragati to know what is late, blocked, and who’s next?*  
If a surface fails that test — **delete it**.

When in doubt: **does this close a real exception faster?**  
If it exists for vanity, industry cosplay, or fear of looking empty — **delete it**.

## Mission

Track work: **projects · tasks · owners · due dates · blockers**.  
The board is the source of truth. Everything else is optional chrome.

## The only loops that matter

1. **Today** — overdue → blocked (with a named cause) → due today → act  
2. **Delivery** — open task → finish it (or name the blocker)  
3. **Lead** — who is late, who is stuck, one export if the room needs paper  

Everything else is secondary or a feature flag.

## Operating rules (Elon algorithm)

1. **Question the requirement.** Is this field / tab / status for everyone, or one industry? Default: everyone.  
2. **Delete before you optimize.** Dead UI means dead code too.  
3. **Simplify.** One home (**Today**). One owner. One date. One next action.  
4. **Accelerate.** Instant shell, optimistic writes, mobile finish in two taps.  
5. **Automate last.** Digest and recurring cron only after the board is honest.  
6. **No invented urgency.** Far-out work stays on the board; it does not steal the morning.  
7. **Blocked without a named cause is a lie.** Status `blocked` requires *waiting on* (person, team, part, decision).  
8. **Assignees finish their own work.** Leads reassign and set structure.  
9. **Celebrate finished work sparingly.** Earned sparkle on phase/project clear — not every checkbox.  
10. **One visual identity.** Classic blue `#1565C0` → forest `#2E7D32`. No theme thrash.  
11. **Empty healthy days say “Zero exceptions.”** Silence is a product feature.  
12. **Recurring is a schedule**, not a fake project on Today.  

## Universal product (not vertical)

- Templates: blank, sprint, release, launch, research, incident, personal — first.  
- Industry / regulated templates may exist as **optional** structure, never the default story.  
- Compliance fields (approval, external ref) are **tools some teams turn on**, not the product’s identity.  
- Language: owner, due, blocked, waiting on, critical — not CAPA / GxP / QMS as the face of the app.

## Explicit non-goals (frozen)

- Delivery Foresight / pace predictions  
- Work Mixer shadow prioritization product  
- Project finish-date forecast chips  
- Full-screen login welcome veils  
- Identity / quote system as a weekly workstream  
- Pharma-first positioning or homepage narrative
